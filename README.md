# 📦 FUSEBOX — Secure Local Document Fusion

## 🔒 Privacy-First Document Merger

**FUSEBOX** is a browser-based tool that merges multiple documents into a single PDF — without ever reading or analyzing their content.

Instead of parsing files, FUSEBOX captures each page as a **full image (like a photograph)** and then fuses those images into one PDF.

> ⚡ Your data is never interpreted, indexed, or sent anywhere — everything happens locally in your browser.

---

## 🚀 Features

- 🔐 **100% Local Processing**  
  No uploads, no servers, no cloud  

- 📸 **Page-as-Image Technology**  
  Each page is captured visually, not parsed  

- 🚫 **Zero Data Extraction**  
  No text reading, no metadata access  

- 📄 **Multi-format Support**  
  PDF, DOCX, XLSX, PNG, JPG, WEBP  

- ⚙️ **Quality Control**  
  Light, Standard, and High output modes  

- ⚡ **Fast & Lightweight**  
  Runs entirely in your browser  

---

## 🧠 How It Works

1. Load your files (drag & drop or browse)  
2. FUSEBOX converts each page into an image  
3. All images are combined into a single PDF  
4. The final file is downloaded locally  

> 💡 Your original file structure and content remain untouched and unread.

---

## 🛠️ Tech Stack

- HTML / CSS / JavaScript  
- PDF.js – PDF rendering  
- jsPDF – PDF generation  
- Mammoth.js – DOCX to HTML  
- SheetJS (XLSX.js) – Excel parsing  

---

## 📥 Supported Formats

- `.pdf`  
- `.docx`  
- `.xlsx`, `.xls`  
- `.png`, `.jpg`, `.jpeg`, `.webp`  

---

## 📦 Usage

Simply open the `fusebox.html` file in your browser:

```bash
# No installation needed
open fusebox.html
```

Or deploy it on GitHub Pages for public use.

---

## 🔐 Privacy Model

FUSEBOX is built on a strict privacy philosophy:

- ❌ No file uploads  
- ❌ No content parsing  
- ❌ No network communication  
- ❌ No cloud storage  

✔️ **Everything stays on your device**

---

## ⚡ Why FUSEBOX?

Most document tools:

- Upload your files  
- Read and analyze content  
- Store or process data remotely  

**FUSEBOX does none of that.**

It treats your files like sealed objects and only captures their visual representation.
